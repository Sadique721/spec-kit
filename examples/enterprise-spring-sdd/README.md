# Enterprise Spring Boot SDD Reference Example

This example demonstrates how **GitHub Spec-Kit (SDD)** is applied to an enterprise Order Fulfillment & Payment Processing microservice:
- **Spec First**: Explicit domain constraints and REST contracts.
- **Architectural Plan**: Spring Boot 3, PostgreSQL, Kafka event streaming, and Flyway migrations.
- **Constitution Gates**: Zero secrets, 100% test-backed PRs, and idempotent payment mutations.
