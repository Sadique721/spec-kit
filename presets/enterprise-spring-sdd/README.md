# Enterprise Spring Boot & Microservices SDD Preset

Designed by **Md Sadique Amin (@Sadique721)**.

This preset extends **GitHub Spec-Kit** with enterprise patterns for:
- **Spring Boot 3 (Java 17/21/25)**: Modular layering (`Controller` -> `Service` -> `Repository` -> `Entity`).
- **Data & Persistence**: JPA/Hibernate, Flyway/Liquibase schema migrations, and optimistic locking.
- **Event-Driven Architectures**: Apache Kafka topics, idempotency keys, Dead Letter Queues (DLQ).
- **Security & Reliability**: Spring Security 6, JWT/OAuth2, Circuit Breakers (Resilience4j), and comprehensive Testcontainers integration.

## Installation

```bash
specify preset add enterprise-spring-sdd
```
